What each one trades off

Nothing here is free. Every approach buys you something and costs you something else.

Tailwind CSS

  • ✓
    Fast to writeno file switching
  • ✓
    Consistent by defaultone spacing & colour scale
  • ✓
    Responsive in placemd:, lg: right on the element
  • ✓
    Fits component codeReact, Vue, Svelte
  • ✗
    Long class listsextract a component once it repeats
  • ✗
    A vocabulary to learna day or two, then muscle memory
  • ✗
    Markup looks noisytrue — that's the trade
  • ✗
    Overkill for tiny sitesplain CSS is fine there

Bootstrap

  • ✓
    Ready-made componentsnavbar, modal, card — done
  • ✓
    Huge ecosystemthemes, templates, decades of answers
  • ✓
    Consistent out of the boxone design language, no bikeshedding
  • ✓
    Low ramp-upmost devs have touched it before
  • ✗
    Generic looksites read “Bootstrap-y” unless themed
  • ✗
    Heavier bundleCSS + JS you may not use
  • ✗
    Overriding fightsbeating specificity to make it yours
  • ✗
    Component lock-inoff-pattern designs fight the grain

Vanilla CSS

  • ✓
    Zero dependenciesnothing to install, nothing to update
  • ✓
    Full controlno framework opinions to work around
  • ✓
    Smallest payloadonly what you write ships
  • ✓
    No abstractionit's just CSS, forever transferable
  • ✗
    Everything from scratchresets, grid, components — all manual
  • ✗
    Naming is on youBEM or however you keep it sane
  • ✗
    Consistency takes disciplineno shared scale unless you build one
  • ✗
    Slower to prototypeno shortcuts for common patterns

Side by side

  Tailwind Bootstrap Vanilla CSS
Bundle size ~10 KB, purged ~25 KB CSS + optional JS 0 KB framework
Learning curve A day or two of class names Low — classes read like English None — it's the CSS you know
Customization High, via config file Medium, via Sass variables Unlimited
Components included None — you compose them Full set — navbar, modal, forms… None
Best for Custom design systems Fast, conventional UI Small sites, learning, tight control
Setup Build step, or a CDN script tag CDN link or npm install No install

If you remember one thing

Bootstrap gives you finished components.
Tailwind gives you building blocks.
Vanilla gives you the whole box of parts.

All three end up as CSS in the browser. The difference is who assembles it, and how much you want to decide yourself.
