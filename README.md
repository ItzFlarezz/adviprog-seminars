# adviprog-seminars

For the seminar 4 demo, run server.js in the jwt-demo directory with node and open localhost:3000

demo is supposed to showcase (without using actual credentials such as passwords) that you cannot access localhost:3000/protected without having a valid and active JWT token in your localstorage. Which you create by "logging in". "Logging out" is just deleting the token from local storage in this case.
